Como ler qualquer um destes códigos

Uma variável (var x = 3) guarda um número ou texto com um nome, para usar depois. Uma função (function nome(entrada) { ... }) é uma receita: recebe algo, faz contas, devolve um resultado. Um laço (for) repete um bloco de código várias vezes — aqui, quase sempre "uma vez por ponto desenhado". ctx é o pincel: ctx.moveTo(x,y) levanta a caneta e pousa num ponto; ctx.lineTo(x,y) risca uma linha reta até o próximo. Tudo o que você vê na tela é um desses três ingredientes, repetidos milhares de vezes por segundo.
