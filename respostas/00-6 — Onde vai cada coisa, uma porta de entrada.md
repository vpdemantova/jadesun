## 6. Onde vai cada coisa (proposta — uma porta de entrada)

| O quê | Onde vive |
|---|---|
| O que fazer hoje | `Tarefas Simples` → página Hoje |
| Estudar | Seleção + Checklist do Vestibular |
| Qualquer coisa nova (nota, foto de papel, ideia solta) | **`Logboard/z Entrada`** — a única porta. Triagem 1× por semana, na rega de segunda: cada coisa ganha destino ou é descartada |
| Ideia de frente nova | uma linha em `CentroPlus` |
| Obras e trabalhos | as estantes do vault (Livro, Poemas, Fotografia, Music…), cada uma com `visibilidade` |
| Papéis físicos | foto → `z Entrada` → transcrição fiel (depois do vestibular) |
